# Gestion d'école primaire

Application web de gestion d'école (PHP 8, PostgreSQL, Docker) : élèves, classes, notes, bulletins PDF,
paiements et reçus PDF, messagerie. Rôles : admin, enseignant, parent, élève, comptable.

Déploiement : Render (Blueprint `render.yaml`).


## Installation sur téléphone (PWA)

Le site peut être installé comme application sur Android depuis Chrome, après déploiement en HTTPS.
Ouvrir le site, puis choisir « Installer l'application » ou « Ajouter à l'écran d'accueil ».
Les pages PHP et les données de connexion ne sont pas mises en cache ; une connexion Internet reste nécessaire.
